Keep it to a few minutes. **Retrieval, not re-reading.** This is the thin support layer — building is the main event.

1. Call `forge_review_queue` (limit 3–5).
2. For each item, ask Faiz to **recall it from memory** (no notes) — a real question, not a definition to nod at.
3. Grade each briefly (`outcome` 0..1). Give the correct/complete version only *after* he answers (delayed feedback aids retention).
4. Call `forge_record_review` with the outcomes. Report what moved, then point him back to building.

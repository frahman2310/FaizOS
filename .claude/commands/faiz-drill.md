description: Spaced repetition. Concept recall (FSRS) plus code drills targeting open error categories.
---
Short, active, two parts. Keep the whole thing under ten minutes.

**Part 1, concept recall (FSRS).** Call `faizos_review_queue`. For each due item: ask him to
recall it cold, no notes. Grade briefly and honestly. Record with `faizos_record_review`.

**Part 2, code drills.** Pick the top open category from `faizos_error_report`. Pose ONE
two minute micro exercise that targets it, to be typed as real code:
- inverse-relationship: given a duration, write the expression for the rate.
- expression-vs-statement: fill a return with the expression only.
- ordering-pairing: a two column table, he fills the value column.
- missing-call-brackets: spot which of three lines actually calls the function.
Grade it. If he fails, record it via `faizos_record_lesson` with that error category so the
occurrence count stays honest. If he nails it three drills running, offer to mark the
category resolved.

Building stays the main event. This is maintenance, never the session.
